# Frontend Template For Software Team Onboarding  

This repository serves as a foundational template for building and scaling the frontend projects of Software Department, SIC. It is designed to provide a consistent structure, pre-configured tooling, and best practices to accelerate the start of new projects.

## Getting Started
To use this template for your next project, click the "Use this template" button on GitHub or clone the repository:

```js
git clone https://github.com/your-username/frontend-template.git your-project-name
cd your-project-name
```

## Setup
1. Install dependencies
   ```js
   npm install -g pnpm
   pnpm install
   ```
2. Run Server
   ```js
   pnpm dev
   ```
